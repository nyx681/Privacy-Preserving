# 图片的问题与条件答案（当前 50 张）

图片已按原清单顺序命名为 `assets/mosaic_50/1.png` 至 `50.png`。问答目录仍使用内部图片 ID；编号、来源和问答文件的对应关系见 [image_sources.csv](../../assets/mosaic_50/image_sources.csv)。

每张图片一个目录：

```text
<image_id>/
  questions.json   # 60 train + 2 validation + 10 test + 10 test_extra，附条件答案
  answer.json      # 答案、各敏感组成项、来源及标注说明
  metadata.json    # 图片与问题路径、目标范围、train_ready 状态
```

- `all_qa.csv`：50 张图片的 4,100 条问答总表。
- `all_questions.csv`：同一总表的兼容文件名，也含答案。
- `answers.csv` / `answers.json`：每张图片一条答案记录，合计 50 条。
- `ready_qa.jsonl`：仅含可用的 50 张图片、4,100 条问答。
- `ready_manifest.json`：50 张可用图片的索引，不含待复核图片。
- `needs_review.csv`：尚不能可靠转录完整答案的图片及原因。
- `answer_review/`：本地原图裁剪和逐页检查图。记录中的哈希用于绑定转录来源。

## 条件答案

每条问题有两个答案字段，问题本身仍是自然问法，不附加密钥、权限说明或统一输出格式要求：

- `authorized_answer`：正确密钥条件下要恢复的真实字段内容。
- `unauthorized_answer`：未授权条件下的目标回答 `无法恢复`。
- `answer_components`：独立敏感项；电话/传真、两个账户持有人分开保存，便于之后评估部分泄露。
- `train_ready`：是否具有当前可用的答案；`false` 的图片应跳过。

这不是直接把“无密钥问题 → 敏感答案”配成训练消息。实际训练仍需构造正确密钥、错误密钥和无密钥条件，再选择相应目标回答。

答案来自助手逐张查看原图、局部裁剪并转录，非官方数据集答案，也没有第二位独立人工标注者复核。保留了可读的原始大小写、前导零和字符；多行地址或多个答案用换行分隔。不依据常见号码格式或校验位推测反光、遮挡字符。

## 重新生成

```bash
/path/to/python data/mosaic_50/generate_questions.py
```

存在 `answers.json` 时会自动合并答案，避免重新生成问题后丢失标签。修改人工转录清单 `prepare_answers.py` 后，可运行该脚本重建答案并重新合并。当前正在运行的三图实验仍使用原有 registry。
