## 处理与去重

沿用原方法：手工查看真实原图并定位目标文字，解码为RGB，将每个遮挡区域用BOX缩小为最多6×2色块，再以NEAREST放大回原大小；按原尺寸保存PNG。重复出现的完整目标文字使用多个遮挡框。每张图只处理标注的目标字段，不宣称遮盖了图中全部隐私信息。

新增28张采用28个不同原图；与原52张、已排除图片比较了RGB像素指纹和64位dHash（汉明距离≤8视为待复核候选，本次无候选）。与训练负例池按原图文件名排查无重叠。80张输出的文件哈希、解码RGB指纹均各有80个唯一值。感知哈希是相似图筛查方法，不等同于对所有可能裁剪或重拍的数学保证。

原图文件不修改；新增图片遮挡框外RGB逐像素不变。来源文字由助手查看原图转录，未经第二位独立标注者复核，不按图片外知识补全模糊字符。第53张仅记录车牌大号数字部分856；第61、66张姓名保留证件印刷行顺序。
